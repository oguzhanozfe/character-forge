# Character Forge Core (Unity package)

Imports packages produced by the character-forge pipeline (`forge package <id>`): Humanoid Avatar from the manifest's
bone map, material from runtime textures, motion clips + `ForgeMotionLibrary` + Animator controller, 20 regional
hitboxes, gore regions with baked gib/stump meshes, a prefab, a turntable/motion preview and EditMode tests.

Menu: `Tools > Character Forge > ...`. Batch: `CharacterForge.Editor.ForgeBatch.ImportCandidate`.
Full guide: `docs/UNITY.md` in the character-forge repository. Contains no third-party or store assets.
